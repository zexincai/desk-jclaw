## ⚠️ 依赖安装问题

遇到 Electron 安装不完整的问题，需要手动修复。

## 🔧 立即执行

请运行以下命令修复依赖：

```bash
# 修复权限
sudo chown -R $(whoami) node_modules

# 删除并重新安装
rm -rf node_modules pnpm-lock.yaml
pnpm install
```
